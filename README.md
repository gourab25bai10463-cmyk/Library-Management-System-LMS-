### **# 📝 TaskFlow \[Library Management System (LMS)]**



##### **## Overview**

TaskFlow is a full-stack web application designed to help remote teams organize, assign, and track daily tasks in real-time. It streamlines workflow management by providing an intuitive kanban board interface, automated deadline reminders, and role-based access control for team members and managers.



##### **## ✨ Features**

\* \*\*Real-time Kanban Board:\*\* Drag and drop tasks across customizable columns.

\* \*\*Role-Based Access Control (RBAC):\*\* Distinct permissions for Admins, Managers, and Users.

\* \*\*Automated Notifications:\*\* Email alerts for upcoming deadlines and task reassignment.

\* \*\*Analytics Dashboard:\*\* Visualize team productivity and bottleneck areas over time.

\* \*\*Dark/Light Mode Toggle:\*\* User-specific UI preferences.



##### **## 🛠 Technologies \& Tools Used**

\* \*\*Frontend:\*\* React.js, Tailwind CSS, Redux Toolkit

\* \*\*Backend:\*\* Node.js, Express.js

\* \*\*Database:\*\* MongoDB, Mongoose

\* \*\*Authentication:\*\* JSON Web Tokens (JWT), bcrypt

\* \*\*Testing:\*\* Jest, React Testing Library
